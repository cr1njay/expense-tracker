# Expense Tracker

A full-stack web app for tracking personal expenses — log transactions, organize them by category, set budgets, and see spending broken down over time.

## Features (planned)
- User accounts with authentication
- Add, edit, and delete transactions
- Organize transactions by category
- Set monthly budgets per category
- Dashboard with spending summaries and charts
- Alerts when a category goes over budget

## Tech Stack
- **Backend:** Python, Flask, Flask-SQLAlchemy
- **Database:** SQLite (development) / PostgreSQL (production)
- **Frontend:** React
- **Charts:** Recharts / Chart.js

## Status
🚧 In progress — currently building out the core API and data model.
